# Emuera Save Studio

[English](README.md) · **한국어** · [日本語](README.ja.md)

브라우저에서 Emuera 세이브를 읽고 수정하는 앱입니다. `global.sav`를 포함한 텍스트·바이너리 세이브를 지원하며, 파일 업로드나 백엔드, 계정, 데이터베이스가 필요하지 않습니다. 앱 화면은 영어·한국어·일본어를 지원합니다.

## 시작하기

로컬에서 실행하려면 Node.js 22.x(22.12 이상), 24.x 또는 26.x와 npm을 설치한 뒤 프로젝트 디렉터리에서 다음 명령을 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. **샘플로 둘러보기**를 선택하면 자신의 파일을 열기 전에 가상 세이브로 사용해 볼 수 있습니다. 호스팅된 앱을 사용하는 경우에는 브라우저만 있으면 됩니다.

최신 데스크톱 브라우저를 사용하세요. 현재 브라우저 테스트는 Chromium에서 데스크톱과 모바일 화면 크기를 대상으로 수행합니다.

## 언어 선택

상단 언어 선택기에서 **English**, **한국어**, **日本語**로 전환할 수 있습니다. 처음에는 브라우저가 선호하는 지원 언어를 사용하고, 지원하는 언어가 없으면 영어를 표시합니다. URL의 언어 지정(`?lang=en`, `?lang=ko`, `?lang=ja`)이 우선합니다. 언어를 선택하면 URL에 반영되어 쿠키나 localStorage를 사용하지 않아도 새로고침 후 유지되며 북마크로 보관할 수 있습니다.

언어를 바꿔도 열린 세이브, 수정 내용, 검색 조건, CSV 이름표는 유지됩니다. 버튼, 도움말, 오류, 알림은 번역하고 파일명, 변수명, 캐릭터명, CSV 이름표, 저장 값은 원문 그대로 표시합니다. 번역은 앱에 포함되어 있어 앱을 불러온 뒤에는 오프라인에서도 전환할 수 있습니다.

## 세이브 편집하기

1. `save*.sav` 또는 `global.sav` 파일 하나를 열거나 화면에 끌어 놓습니다.
2. 공통·글로벌 변수 또는 캐릭터를 선택합니다. 변수명, CSV 이름표, 정확한 배열 인덱스로 검색할 수 있습니다. 다차원 인덱스는 `1:2:3`으로 입력합니다.
3. 값을 클릭하고 새 값을 입력한 뒤 변경을 적용합니다. **변경 내역** 탭에서 원본과 현재 값을 비교하고 개별 변경 또는 전체 변경을 되돌릴 수 있습니다.
4. **세이브 다운로드**를 선택하여 `original-name.edited.sav`를 저장합니다.
5. 원본의 백업을 보관한 뒤 수정본을 원래 파일명으로 바꿔 게임의 세이브 폴더에 넣습니다.

앱은 별도 파일을 다운로드하며 원본을 덮어쓰지 않습니다. 다운로드한 파일은 원래 형식과 인코딩을 유지합니다. 변경하지 않았다면 원본과 바이트 단위로 동일합니다. 수정본은 다운로드 전에 검증하지만, 게임의 규칙이나 각 값의 의미까지 확인하지는 않습니다.

## CSV 이름표와 인코딩

**CSV 불러오기**에서 게임의 `ABL.csv`, `TALENT.csv`, `EXP.csv`, `PALAM.csv`, `ITEM.csv`, `FLAG.csv`, `CFLAG.csv` 등 지원하는 표준 이름표 파일을 선택합니다. 여러 CSV를 함께 선택할 수 있습니다. 이름표는 값을 이름으로 찾도록 돕는 선택 기능이며 세이브 내용이나 배열 크기를 바꾸지 않습니다. 이름표가 충돌하면 먼저 읽은 이름을 유지하고 알림을 표시합니다.

텍스트 인코딩은 UTF-8을 먼저 검사하고, 유효하지 않으면 CP932/Shift-JIS를 사용합니다. 일부 바이트열은 두 인코딩에서 모두 유효합니다. 글자가 잘못 표시되면 **읽기 인코딩**을 올바르게 선택하고 **선택한 인코딩으로 다시 읽기**를 누르세요. 다시 읽을 때는 확인을 거쳐 변경 사항을 버립니다. 선택한 인코딩은 이후에 불러오는 CSV에도 적용됩니다.

## 호환 범위

기준은 커밋 [`85db4cbd`](https://github.com/0x00000FF/Emuera/tree/85db4cbd5eb2efe6c5b5449ada351a21a20db60b)에 보존된 표준 **Emuera 1.824**입니다.

| 항목 | 지원 범위 |
| --- | --- |
| 세이브 종류 | 일반 진행 세이브와 글로벌 세이브 |
| 텍스트 세이브 | 기본·확장 구역, BOM 유무와 관계없는 UTF-8, CP932/Shift-JIS |
| 바이너리 세이브 | 형식 버전 1808 |
| 값 | 부호 있는 64비트 정수, 문자열, 최대 3차원 배열 |
| 편집 | 기존 값, 선언된 바이너리 배열 범위 안에서 생략된 0·빈 문자열 |
| 크기 제한 | 파일당 64 MiB, 바이너리 배열당 1억 요소, 저장된 값 100만 개, 텍스트 100만 줄 |

흔히 “CSV 세이브”라고 부르는 텍스트 세이브는 Emuera 고유 형식이며 이름표용 CSV 파일과 다릅니다. 1700, 1708, 1729, 1803, 1808 텍스트 확장 구분자를 인식하며, 호환성 검증은 기준 엔진이 생성한 1808 형식에 초점을 맞춥니다.

캐릭터·변수 추가 및 삭제, 배열 크기 변경, 형식 변환, ERB/ERH 실행, `_Rename.csv` 치환, EM/EM+EE 고유 확장은 지원하지 않습니다. 텍스트 배열에서 생략된 끝부분은 선언된 크기를 알 수 없어 편집할 수 없습니다. 텍스트 다차원 문자열 배열은 기준 엔진에서 지원하지 않습니다. CSV 이름표는 캐릭터 CSV로 게임 구조를 추론하지 않습니다.

범위를 벗어난 정수, 원본 텍스트 인코딩으로 표현할 수 없는 문자, 예약된 텍스트 구분자, 텍스트 값의 줄바꿈, 손상되거나 지원하지 않는 파일은 오류로 처리합니다. 호환성 검증에는 원본 엔진의 저장 코드로 생성하고 읽은 가상 세이브를 사용하며, 실제 사용자 게임 세이브로는 아직 검증하지 않았습니다.

## 개인정보와 작업 내용

세이브와 CSV 내용은 브라우저 메모리에만 보관합니다. 업로드 API, 분석 도구, 외부 폰트, CDN 의존성이 없으며 작업 내용을 쿠키, localStorage, IndexedDB에 저장하지 않습니다.

앱을 불러온 뒤에는 네트워크 연결 없이 편집, CSV 불러오기, 다운로드가 가능합니다. 새로고침하거나 페이지를 닫으면 작업이 사라지므로 먼저 수정본을 다운로드하세요. 오프라인 재접속·PWA 설치와 `file://`로 HTML을 직접 여는 방식은 지원하지 않습니다.
